# Images des plats

Le dossier `kebab-sasha/` contient les 128 variantes du Kebab Sasha. Les suffixes de fichiers indiquent les ingrédients présents : `V` viande (toujours incluse), `S` salade, `T` tomates, `O` oignons, `C` cornichons, `B` bacon, `R` oignon frit et `F` fromage. Le site sélectionne la bonne image selon les ingrédients retirés. Ne renomme pas les fichiers `wrap_001_...png` à `wrap_128_...png`.
