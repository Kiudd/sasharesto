# Images des plats

Dépose les fichiers image dans ces dossiers, en PNG avec fond transparent si possible :

- `plate/plate.png` — l'assiette (commune à tous les plats)
- `bases/` — les bases des plats. La tortilla `tortilla.png` sert au kebab Sasha, au dürüm et au wrap falafel. Les autres bases pourront être ajoutées ici ensuite.
- `ingredients/` — une image par ingrédient, nommée avec son identifiant. Les variantes de frites utilisent `frite.png`, `frites-cheddar.png`, `frites-bacon.png`, `frites-oignon.png`, `frites-bacon-oignon.png`, `frites-cheddar-bacon.png`, `frites-cheddar-oignon.png` et `frites-cheddar-bacon-oignon.png`.

Exemples de chemins complets : `public/images/food/plate/plate.png`, `public/images/food/bases/assiette.png`, `public/images/food/ingredients/poulet.png`.

Garde ces noms de fichiers pour que je puisse ensuite relier chaque image au bon élément du visuel. Tu peux déposer les images directement dans les dossiers correspondants.
